This is the checklist a VIO pipeline is certified against. Every row exists because its failure
happened here; the [storyline](storyline.mdx) tells which. A row's **pass criterion** is
independent of cortex, so it carries over to another pipeline. The **test here** column names the
cortex test case that implements it (Catch2 case names, under `tests/`).

**Status:**

- **locked:** asserted in CI.
- **characterization:** a test pins a known defect, so a fix flips it.
- **partial / weak:** a test exists but doesn't yet assert the full criterion.
- **gated:** skipped in CI, which has no EuRoC dataset; run locally.
- **warn:** runs and reports, doesn't assert.
- **missing:** no test yet; the issue beside it tracks one.

<Aside type="tip" title="Certifying a new pipeline">
  Work top to bottom. Section A comes first because a wrong test world invalidates every result
  below it. Run each stage row (B) in isolation before the assembled filter (C), and the
  synthetic system tests (D) before real data (E). A pipeline is certified when every row passes
  its criterion; a row it can't yet pass is recorded as a characterization, with the measured
  value, never silently skipped.
</Aside>

## F. Engineering hygiene

| # | Requirement | Pass criterion | Status |
|---|---|---|---|
| F1 | Two or more compilers in CI, whole suite | GCC and Clang per-frame traces bit-identical; MSVC also runs | locked |
| F2 | Portable test noise | Gaussian draws built from the raw engine output, so every platform sees the same realization for a seed | locked (the S10 controls) |
| F3 | Refactors preserve bits | `bench_snapshot --compare --rel 0` over every output, worst difference 0; the EuRoC `run.jsonl` byte-identical, or a justified exemption of 1e-12 or less | locked |
| F4 | Tools fail loudly | A missing output directory is an error, not a silent skip | locked |
